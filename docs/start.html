⚗️ Vault Alchemist

初回セットアップ

1
ターミナルでインストールする

Mac のターミナルを開き、以下のコマンドをコピーして実行します。自動でインストールが完了します。

% curl -sL https://raw.githubusercontent.com/matsulinks/vault-alchemist/main/install.sh | bash
→ 保管庫を検出してインストールします...
2
制限モードをオフにする

Obsidianを開き、設定 → コミュニティプラグイン から「制限モード」をオフにします。

オプション
一般
エディター
プラグインオプション
コミュニティプラグイン
制限モード オフにするとコミュニティプラグインが使えます
3
Vault Alchemistを有効にする

インストール済みプラグインの一覧から「Vault Alchemist」を探して「有効化」を押します。

📝
Calendar
Simple calendar view
⚗️
Vault Alchemist
AIを使ったVaultアシスタント
4
OpenAI APIキーを入力する

設定 → Vault Alchemist を開き、APIキーを貼り付けます。キーはこちらから取得できます: platform.openai.com/api-keys
